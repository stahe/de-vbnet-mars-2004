# Einführung in VB.NET anhand von Beispielen

👉 Verwandter Kurs: [Einführung in VB.NET anhand von Beispielen](https://stahe.github.io/de-vbnet-mars-2004/)

## Inhalte

Dieser Kurs behandelt die folgenden Hauptthemen:

- Grundlagen von VB.NET
- Objektorientierte Programmierung
- Grafische Benutzeroberflächen (GUI)
- Ereignisbehandlung
- Datenbankzugriff
- TCP/IP-Programmierung
- Webdienste

## Zielsetzung

Eine schrittweise Einführung in VB.NET anhand praktischer Beispiele, die alle Themen von den Grundlagen bis hin zu anwendungsspezifischen Bereichen (GUI, Netzwerke, Daten, Webdienste) abdeckt.

Serge Tahé, März 2004
